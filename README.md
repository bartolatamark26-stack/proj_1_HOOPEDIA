# Hoopedia — The Basketball Knowledge Library

Hoopedia is a static website that provides information about basketball rules, skills, strategies, history, and player positions. It serves as a simple reference for basketball players, students, and fans who want to learn more about the game.

## Features

- Learn about basketball rules, scoring, fouls, and violations
- Read guides about passing, shooting, rebounding, and other techniques
- Understand offensive, defensive, and transition strategies
- Explore basketball history and player positions
- Search for basketball article topics
- Navigate between pages easily
- Responsive navigation for smaller screens

## Pages

- `index.html` — Home page
- `rules.html` — Basketball rules, scoring, fouls, and violations
- `plays.html` — Basketball plays and individual techniques
- `strategies.html` — Offensive, defensive, and transition strategies
- `history.html` — Basketball history
- `positions.html` — Player positions and shared skills

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the available basketball topics.

No database or server setup is required.

## Project Purpose

Hoopedia was created to make basketball information easy to access through a simple and organized website.
